Read the supplied job's `spec.md`. Preserve the feature request and repository profile; add a short scope and clear, observable acceptance criteria. Respect the repo's Flutter/Dart conventions and validation commands in the brief. Write only `spec.md` in that job folder. Do not edit product code or the board.
