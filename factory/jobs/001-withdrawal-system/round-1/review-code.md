- `functions/index.js` (`requestWithdrawal` payout `catch`): wallet funds are reserved in the Firestore transaction before Cashfree authorization. `getAuthToken()` can throw an `HttpsError` when payout credentials are missing, and `verifyToken()` throws one when token verification fails. The catch immediately rethrows every `HttpsError` before checking `transferRequestStarted` or calling `finishWithdrawal`, leaving the withdrawal pending and the amount stranded in `pendingBalance` instead of restoring it. Roll back reservation for every known pre-transfer failure before returning the error (while retaining pending state only for ambiguous outcomes after a transfer request may have reached Cashfree). Add focused coverage for missing credentials/token-verification failure and assert the withdrawal is failed and balances are restored.
